### About me

I'm a **Software Engineering** student focused on **applied AI and automation**: products and workflows where an AI model does part of the job and the result still has to be reliable.

My most proven skill today is **QA automation with Python**. I've built API and UI test suites with pytest, Requests and Selenium that run in GitHub Actions CI. I use that testing background to decide how an AI feature should behave and what has to be checked before it ships.

I also build products with AI coding tools: I write the specs, UX decisions and acceptance criteria, and review what gets built. Next, I'm going deeper into **data and SQL**.

### Featured projects

**[Totem Barbearia](https://github.com/arthurdtz/totem-barbearia)** · Collaborative project · React, Express, Google Gemini

A web app that shows a barbershop client AI-generated previews of haircuts and beards from their own photo.

- **What the product does:** photo capture or upload, style suggestions, AI previews with Gemini, before-and-after comparison, and favorites. Requests are validated and rate-limited before they reach the AI provider.
- **What I did:** contributed to product and UX, helped define the user flow, and set up the Gemini API key and prompt.
- **Still planned:** automated tests and a formal evaluation of the AI output against a rubric. Neither has been run yet.

**[QA Automation Portfolio](https://github.com/arthurdtz/qa-automation-portfolio)** · Python, pytest, Requests, Selenium, GitHub Actions

- API tests for an authenticated REST API: GET (200 and 404), POST 201, PUT 200 and DELETE 204.
- Selenium UI tests for a login page (valid user, invalid user, invalid password) with the Page Object Model.
- GitHub Actions runs both suites on every push and pull request and publishes HTML reports.
